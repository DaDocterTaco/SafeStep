# SafeStep

SafeStep is a Chrome extension that guides browsing tasks, explains website and download risks, and helps compare shopping options. Its chat interface uses nine feature modules.

The published source corresponds to **0.8.12**, build **`stage-8-5408437fcdf4`**. The WinSCP demo distinguishes the official installer and portable package routes and previews eligible labeled ads for cleanup and restoration. Manual guidance and automatic navigation are distinct modes. Focused independent testing on 0.8.11 verified live cleanup and restore and found interrupted automatic navigation. Builder checks on this 0.8.12 build confirmed the corrected guide arrow placement, unobstructed click target, instructions and accessible description at both desktop sizes. A 1366 × 768 Firefox run passed; a 1440 × 900 Phishing run subsequently timed out finding the compact Show step control. Independent acceptance of 0.8.12 is pending.
