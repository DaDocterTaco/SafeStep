# SafeStep

SafeStep is a Chrome extension that guides browsing tasks, explains website and download risks, and helps compare shopping options. Its chat interface uses nine feature modules.

The published source corresponds to **0.8.11**, build **`stage-8-2aeb36f98542`**. The WinSCP demo distinguishes the official installer and portable package routes and previews eligible labeled ads for cleanup and restoration. Manual guidance and automatic navigation are distinct modes. Focused testing on this build verified live cleanup and restore and found an interruption during automatic navigation. Uninterrupted automatic completion remains unverified.
