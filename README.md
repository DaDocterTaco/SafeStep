# SafeStep

SafeStep is a Chrome extension for guided browsing, address and website-risk explanations, download guidance and shopping assistance. The Stage 8 chat interface routes requests to the existing feature modules.

This branch backs up version **0.8.6**, frozen as **`stage-8-c028a8deb799`**. Its scope is the current all-nine-feature work on Wikipedia, VideoLAN and Resell.store, including automatic URL protection. The broader live site checks, provider validation, final UI and independent acceptance remain open on this fingerprint.
