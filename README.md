# SafeStep

SafeStep is a Chrome extension for guided browsing, address and website-risk explanations, download guidance and shopping assistance. The Stage 8 chat interface routes requests to the existing feature modules.

This branch backs up version **0.8.6**, frozen as **`stage-8-35d021b232e3`**. Its scope is the current all-nine-feature work on Wikipedia, VideoLAN and Resell.store, including automatic URL protection. The builder marked this functional checkpoint ready for final design verification. Independent acceptance on this fingerprint, final UI and the judged release remain open.
