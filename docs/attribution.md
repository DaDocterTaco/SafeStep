# Dependencies and attribution

The extension uses WXT, Vite, React and React DOM. Zod validates contracts, tldts supplies public-suffix parsing, and the Google Gen AI SDK supports the optional server connector. Puppeteer Core and the TypeScript tools support development and browser checks.

The table lists third-party packages declared directly by the root and workspaces, with versions and license fields from the [frozen dependency lock](../package-lock.json). Transitive dependency versions and integrity hashes are in the lockfile. The package distributions contain their license texts.
